### How it works (three steps)

1. **Pick a template.** Levelling, PvP, a game mode, or your own settings. Private (friends with a link) or public.
2. **Name it and press Host.** The launcher gets the Host pack and sets everything up. You see each step.
3. **You're live.** A public realm is on the list in the launcher, on the site and in the game about a minute later.

### What you get

- **Listed for everyone.** Order is by players online, uptime and a small boost while you're new. No paid placement.
- **No port forwarding.** Your realm calls out over one connection; nobody sees your home address, and you never see
  your players'.
- **Your own game folder.** The realm reads what it needs from your folder on your PC. Nothing is downloaded from us
  and nothing leaves your PC.
- **A console in the launcher.** Status, announcements, message of the day, kick and ban, an allow list, a health
  check, restarts with a warning for players.
- **Invite links** for friends, new ones any time.
- **House rules** shown before anyone joins.
- **The Realm Host role** on the Discord after 7 days listed, and a spot in the Realm of the week.

### What you need

| | |
|---|---|
| A PC that stays on while you host | Windows, macOS or Linux |
| Docker | Docker Desktop (Windows, macOS) or Docker Engine (Linux). Free. The Host page checks it and helps. |
| Your own game folder | For the era you want to host |
| Memory | 8 GB (the realm uses about 4 GB); 16 GB if you still want to use the PC |

Already run a server? **Link my server** puts it on the list without changing it (/wrath/docs/join-network).

### Not ready to host? Carry the network

A community node passes players along to realms: a small program, no game files, no realm of your own
(/wrath/docs/be-a-node). Node Keepers are thanked in every State of Leyline.
