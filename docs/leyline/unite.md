# Working together

**This page is a proposal.** Nothing on it is built or agreed. It is a starting point for talks between communities, and every part can change.

The idea: community servers keep their own realms, rules, staff and players, and share the parts that are tedious to build alone. Nobody has to give anything up to join, and anyone can leave.

## What we'd share

1. **One mod format.** Mods written once that run on any realm that adopts the [mod format](mods.md). Each server still picks which mods it runs.
2. **One realm list.** Every server that wants to can list its realms in one place, with the same [record schema](cross-server.md#the-realm-record-and-listing-schema). Order is live first, then by name. Never money, never votes.
3. **Relays run by more than one group.** Communities run their own relays, and the relays share their lists through a directory. No single group can switch the network off.
4. **One sign-in, if players want it.** A player could use one key, such as a [Hero Key](hero-key.md), to prove who they are on many realms. Each server keeps its own accounts and its own bans.
5. **Shared safety lists.** Servers could share relay blocklists for realms that abuse players or the network, with a clear reason for each entry.

## What would stay separate

- Each server's accounts, characters, databases and economy.
- Each server's rules, staff and moderation.
- Each server's client setup. Leyline would never patch or change another server's client.

## Ground rules we'd propose

- **No game data** in anything shared.
- **Open source** for the shared parts, under a licence everyone can use.
- **Bots labelled** everywhere they appear, and counted apart from players.
- **No paid placement** on any shared list.
- **Leave any time.** A server can stop listing or stop using a shared part, and nothing of its own is lost.

## Possible first steps

These are ideas, not promises:

1. Other servers try `mods/wu-mod.py` on their own addons and tell us what the format is missing.
2. A second group runs a relay, and the two relays list each other's realms by hand.
3. A shared document for the record schema, with changes agreed in the open.
4. A friends list across realms, which the in-game Leyline window already has a place for.
