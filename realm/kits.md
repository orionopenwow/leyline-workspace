# WrathUnleashed main realm: spec kits (boost to 80)

Generated by `gen_kits.py` from AzerothCore world data (the realm core's `item_template`, loot, vendor and quest
tables). Every item is obtainable in the game data, usable by the class (AllowableClass), of the class's best
armor type or a weapon type the class trains, for all races, soulbound (bind on pickup: nothing in a kit can be
traded or auctioned), and needs no profession, reputation or honor rank.

* **PvE (Entry)**: the Heroes' T7 10-man set (ilvl 200) plus the best-fitting ilvl 195-205 epic/rare for every
  other slot (Naxxramas-10, Obsidian Sanctum / Eye of Eternity / Vault-10, heroic dungeons, Emblem of Heroism).
* **PvP (Entry)**: the Deadly Gladiator's (season 5, ilvl 213) set, Deadly Gladiator's off-pieces, weapons and
  relic, Medallion of the Alliance / Horde (by faction) and a Battlemaster's trinket; slots with no Deadly item
  use an ilvl 200-213 resilience item (Titan-Forged, Battlemaster's).
* Tanks have no PvP tier set: Protection warriors / paladins and Blood DKs get the plate damage PvP kit (with a
  two-hander), bears the feral cat PvP kit.
* Hand-check overrides: restoration shaman PvP set = Ringmail (mp5). Relics by name (below).
* Relics carry no stats in the database (the effect is a spell), so they are mapped by name (marked *hand*).
* 'spell power' / 'attack power' on a line = an equip spell that the generator attributes to that stat (the spell
  appears only on caster / only on physical items).
