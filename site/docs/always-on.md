# Keep your realm up 24/7

This page was about keeping a realm hosted from home on the Leyline network day and night. The relay and the public
realm list it relied on closed with Leyline's own server in November 2026.

If you run a server of your own on a rented machine, its own software's guides cover keeping it up. To have it on
Leyline's realm list, ask on the [Leyline Discord](https://discord.gg/RfChVr8J7T).
