# Be a node

Be a node let your PC help carry the Leyline network: share Leyline's own files and relay traffic while idle. The
network it helped closed with Leyline's own server in November 2026, so the feature is off for everyone. Nothing on
your PC needs to change: a node that is off does nothing.

Next, community relays run by players carry the network instead: see [The way forward](way-forward.md).
