# Getting started

Leyline plays with game files you already have. It never downloads, hosts or links to the game. This page gets you
from nothing to playing, on your own PC or on a community server.

## Four steps

1. **Get the launcher.** Every download is on the [download page](/wrath/download). It keeps itself up to date.
2. **Add your game folder.** In the launcher, open **Game folders** or press **PLAY** with no folder added, and
   choose the folder you play from. The launcher reads the version itself and names the folder for you.
3. **Pick a way to play.** In the play bar's realm list: **Single player** (your own world on this PC), **Your Den**
   (your own white world to build in), or a server from the [realm list](/wrath/leyline/realms).
4. **Play.** Press **PLAY**. For a server, the launcher points your game at it and keeps your original settings as a
   backup.

## Where your files usually are

The right folder holds the game's program and a `Data` folder.

| On | Look in |
|---|---|
| Windows | `C:\Program Files (x86)`, `C:\Games`, your Desktop or Downloads |
| Mac | `Applications` or your home folder |
| Linux | `~/Games`, or a Wine, Lutris or Bottles prefix under `drive_c` |

Other places worth a look: an old drive or PC, a backup, or a cloud copy. Put the whole folder back on this PC, then
choose it. The launcher has the same tips on its **Find your game files** page.

## Playing on a community server

Each server on the realm list is run by other people, with its own accounts and rules. Make your account on the
server's own website (the list links it), then pick the server in the launcher and press **PLAY**. The list says
which game version each server takes.

## Your Den

Your Den is your own white world to build in, on your PC. Open **Your Den** in the launcher and press **Play solo**.
The first time, it downloads the small Den program; after that no internet is needed. See [Your Den](den.md).

## Common fixes

- **The launcher says the folder isn't a game folder.** Choose the folder that holds the game's program and the
  `Data` folder, not a folder inside it.
- **The server needs a different version.** The realm list says which one. Add that game folder, or pick a server
  for the one you have.
- **The game can't connect to a server.** Check the server's own website or Discord: Leyline does not run it. Then
  delete the `Cache` folder next to the game and start it again.
- **You changed the realm by hand before.** Realms › **…** › **Use my own realmlist** puts back what you had.
- **Still stuck?** Ask on the [Discord](https://discord.gg/RfChVr8J7T).
