# Host for friends

Hosting for friends far away went through the Leyline relay, which closed with Leyline's own server in November
2026. Friends on the same network as you (the same home or LAN) can still play with you: see [Friends](friends.md)
and [Your Den](den.md). Today's steps: [Play with friends](guide-play-with-friends.md). What comes next:
[Joining a world](joining.md).
