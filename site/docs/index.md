# Leyline

Leyline is a desktop launcher for the game clients you already have. It finds your game folders, lists community
servers, runs single player and Your Den on your own PC, and installs mods and addons from the people who made them.
Everything is on GitHub under the MIT licence.

## Leyline runs no server of its own now

Leyline's own server closed in November 2026. With it went the official realm, the relay that let people host
from home without opening ports, the public realm list that hosts joined by themselves, sign-in (the Hero Key and
Google), the forum, the leaderboards, the browser game, the Den market and the release mirror.

## The aims

- **Your files stay yours.** Leyline never downloads, hosts, shares or ships game files.
- **One open mod format.** A mod is a folder with a `mod.json`. One checker tool enforces every rule.
- **Fair by design.** No shop and nothing to buy. The realm list is never ordered by money or votes.
- **Open code.** Anyone can read it, build it, and run their own copy.
