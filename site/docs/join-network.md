# Bring your server

This page was how an existing server joined the Leyline network, with Hero Key sign-in for its players. Both closed
with Leyline's own server in November 2026.

Run a server and want it on Leyline's realm list? The list is now chosen by hand: ask on the
[Leyline Discord](https://discord.gg/RfChVr8J7T) with your server's name, its realm list address, its website and
the game version it takes. Players make their account on your own site.
