# How the Leyline network worked

Leyline used to run a relay and a public realm list, so anyone could host a realm from home and have it listed by
itself. Both closed with Leyline's own server in November 2026.

## What the realm list is now

- A short list of community servers, chosen by hand, each with its owner's OK. It is a plain file on the website.
- Leyline does not run, check or vouch for those servers. Each has its own accounts, rules and staff.
- There are no live player numbers on the site. The launcher checks each server itself when it shows the list.

## What we never do

- Ship, host or share game files.
- Order the list by money or votes.
- Ask for your password to any server.
